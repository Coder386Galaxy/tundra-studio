How Tundra Studio works

🔑 The only AI is your API key

Tundra Studio has no built-in AI. You bring a key (OpenAI or any OpenAI-compatible endpoint — local LLMs included), pick a model, and prompts go straight from your browser to your endpoint. No middleman, no studio account. Without a key the studio still works — you just code by hand.

⚡ Generate writes a whole game from your description. → Apply to code revises the current file from an instruction ("add touch controls", "fix the collision bug"…).

⌨️ The Code Room — no AI

The Code Room is a workspace with zero AI in it: no prompts, no assistant, nothing calling out to a model. Pick your language — JavaScript (complete HTML document), Python (via Pyodide), Lua (via Fengari) or Frost, the hypereasy game language (one instruction per line, runs natively) — and just write.

Real editor: syntax highlighting per language, line numbers, tab/indent, Ctrl+Enter to run, Ctrl+S to save. Python and Lua use a small Tundra game API (draw, input, score, juice) and run in the browser — the publish build wraps them automatically.

Hand-written Starter game and Empty file templates exist for every language — zero AI involved. Want a model's help later? The Forge page can open an AI assistant on your file — never the other way around.

🏪 Publishing to Tundra Games

Tundra Games stores its catalog in browser localStorage and moves it with Publish → Data → Export/Restore JSON. Tundra Studio emits that exact schema:

{
  "games":  [{ id, title, studio, price, date, age,
               tags, platforms, featured, blurb, desc,
               image, screens, palette, discount, gameHTML }],
  "news":   [{ date, title, body, game }],
  "promos": {}, "users": …, "reviews": …
}

So a publish is one Restore away. The extra gameHTML field rides along with the catalog (the store ignores fields it doesn't know), keeping the playable build attached to its listing.

🔐 Everything stays yours

Projects, media and settings live in your browser; games live as files you download. Your prompt never leaves the machine except to the AI endpoint you configured.

The optional TUNDRA_META comment at the top of your file just pre-fills the store kit — delete it whenever, it never affects the game.
