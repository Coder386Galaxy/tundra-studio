TUNDRA GAMES STORE PATCH — install guide
========================================

WHAT THIS ADDS to the store (index.html in this folder = your current
store + everything below):

1. DOWNLOAD-ONLY GAME DELIVERY
   You have to download the game to play it (like a real game store):
   - Library: the big button is "Download" — saves the game as a
     single .html file (double-click to play, works offline)
   - Store page of an owned game: "Download"
   - After purchase: "Download <title>" buttons right in the receipt
   Games published from Tundra Studio are fully self-contained files
   (with the 10s Tundra boot screen), so a download is the whole game.

2. TUNDRA CHECKOUT (from before) — Steam-style wallet top-up:
   "Add funds" buttons, 4-step checkout (Amount -> Payment -> Review ->
   Receipt), and top-up-during-purchase when the wallet can't cover the
   cart (then the purchase completes automatically). Simulation only —
   fictional payment methods, nothing real is charged.

FILES
  index.html                 the complete store — upload this one
  tundra-checkout-addon.js   the checkout addon source (already built in)
  build.py                   rebuilds index.html from the live store source

HOW TO INSTALL — option A (web upload, 60 seconds)
1. Open https://github.com/Coder386Galaxy/Tudra-Publishing
2. Click index.html -> the pencil (Edit file) or Add file -> Upload files
3. Replace the contents with this folder's index.html
4. Commit directly to main
5. Live in ~1 minute at https://coder386galaxy.github.io/Tudra-Publishing/

HOW TO INSTALL — option B (assistant pushes it)
Add the Tudra-Publishing repo to the fine-grained token's access with
Contents: Read and write, send the token, and it will be pushed + verified.

HOW TO PLAY A GAME NOW
Buy or claim it -> "Download <title>" (or Library -> Download) ->
open the downloaded .html file. It boots for ~10 seconds and plays.
