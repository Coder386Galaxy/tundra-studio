TUNDRA GAMES STORE PATCH — install guide
========================================

WHAT THIS ADDS to the store (index.html in this folder = your current
store + everything below):

1. GAMES ACTUALLY LOAD — download gate + player
   - Not downloaded yet: the button is "Download" (also in the purchase
     receipt). Downloading saves the single-file game AND installs it.
   - Downloaded: "Play" opens the game in the store's player (Esc or
     Close exits). You have to download the game before you can play.
   - Sessions, play time, saves and achievements keep working.

2. NO FREE MONEY — Tundra Checkout is required
   The old instant "+$5 … +$100" wallet buttons are gone. Every top-up
   goes through Tundra Checkout: Amount -> Payment method (Visa,
   Mastercard, American Express, PayPal) + payment details (card number,
   expiry, CVC — validated) -> Review -> Receipt. Buying a game you
   can't afford tops up the shortfall first and then completes the
   purchase. The demo store processes nothing real — no card is charged
   or stored.

FILES
  index.html                 the complete store — upload this one
  tundra-checkout-addon.js   the addon source (already built in)
  store-source.html          snapshot of the store source it patches
  build.py                   rebuilds index.html (python3 build.py)

HOW TO INSTALL — option A (web upload, 60 seconds)
1. Open https://github.com/Coder386Galaxy/Tudra-Publishing
2. Click index.html -> the pencil (Edit file) or Add file -> Upload files
3. Replace the contents with this folder's index.html
4. Commit directly to main
5. Live in ~1 minute at https://coder386galaxy.github.io/Tudra-Publishing/

HOW TO INSTALL — option B (assistant pushes it)
Add the Tudra-Publishing repo to the fine-grained token's access with
Contents: Read and write, send the token, and it will be pushed + verified.

HOW TO PLAY A GAME NOW
Buy or claim it -> "Download" (required once) -> "Play" -> the game
loads in the player: ~10 second Tundra boot, then the title screen.
